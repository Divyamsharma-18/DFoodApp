# 🍔 DFoodApp — *When Hunger Meets JavaScript*

Welcome to **DFoodApp** — the place where **your cravings** get the respect they deserve 😤👏
No complicated UI. No "Sign up to continue." No push notifications asking for your kidney.

Just **pure, instant food menu goodness**.

Live Demo 🍱 → **[https://dfoodapp-by-divyam-sharma.netlify.app/](https://dfoodapp-by-divyam-sharma.netlify.app/)**

---

## 🤤 What is This?

A **simple, clean and aesthetic** food ordering UI concept.
Think of it as Swiggy/Zomato's *less dramatic, smol cousin* who just believes in ✨ good vibes and clean layout ✨.

You can:

* Browse menu items 🍕🍔🍟
* See prices 💵
* Pretend you're rich and add everything to cart 🛒
* Actually not order anything (because this is a UI demo 😄)

## 📦 Installation (For Chefs Who Want to Cook Locally)

```bash
# Clone the repo
git clone https://github.com/Divyamsharma-18/DFoodApp.git

# Move into the kitchen
cd DFoodApp

# Install ingredients
npm install

# Cook and serve
npm run dev
```
